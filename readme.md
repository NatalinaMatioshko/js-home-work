## JavaScript Objects Practice

Task 1 — Car

1. ***

Goal:
Create an object that describes a car and implement methods to work with it.

Includes:

Properties: manufacturer, model, year, averageSpeed, fuelTankCapacity, fuelConsumption, drivers

Methods:

showInfo() — shows all car details

addDriver() — adds a driver to the list

hasDriver() — checks if a driver exists

calculateTrip() — calculates total time and fuel for a given distance

Task 2 — Time

2. ***

Goal:
Create an object that describes time and allows modifying it.

Includes:

Properties: hours, minutes, seconds

Methods:

showTime() — displays time in hh:mm:ss format

addSeconds() — adds seconds and adjusts minutes/hours if needed

addMinutes() — adds minutes and adjusts hours if needed

addHours() — adds hours and resets after 24

Task 3 — Fraction

3. ***

Goal:
Create an object that describes a fraction and supports arithmetic operations.

Includes:

Properties: numerator, denominator

Methods:

showFraction() — displays the fraction

getGCD() — finds the greatest common divisor

reduce() — simplifies the fraction

add(), subtract(), multiply(), divide() — perform arithmetic operations

All tasks demonstrate:

Object creation and methods

Use of this

Logical and mathematical operations

Recursive function usage (getGCD)

Three JavaScript tasks were completed to practice working with objects, methods, calculations, and logical operations
