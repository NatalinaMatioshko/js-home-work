## Minimun

## #1 task

Perform the addition of 0.1 and 0.2 to obtain a mathematically correct answer.

## #2 task

Perform the addition of the string “1” and the number 2 (both operands must be in variables) to obtain a mathematically correct answer.

## #3 task

The user specifies the capacity of the flash drive in GB. The program must calculate how many 820 MB files can fit on the flash drive.
